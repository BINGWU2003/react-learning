## 常见边界

- React 输入框在受控与非受控模式之间切换会产生警告；初始值应保持类型稳定。
- `v-model` 不是不可解释的“魔法双向绑定”，组件上会展开为 prop 与 `update:*` 事件。
- 表单值转换应放在输入边界，避免业务层同时处理字符串、数字和空值。
- 大型 React 表单可用 React Hook Form 减少整棵表单的受控更新，见[表单校验实践](/form-validation/)。
